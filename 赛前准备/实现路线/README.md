# B题实现路线目录说明

本目录存放 B 题后续落代码和联调使用的最终实现规范。

## 阅读顺序

1. 先阅读 `B题最终实现路线.md`，确认统一参数、几何判定、时间线规则和四个问题的实现顺序。
2. 按文档中的模块接口分工开发，所有队员使用同一份参数和事件定义。
3. 每完成一个模块，先运行对应验收测试，再与其他模块联调。
4. 代码和结果稳定后，再根据文档中的输出清单整理英文论文。

## 目录约定

建议后续在仓库中建立以下代码结构：

```text
src/
    config.py
    geometry.py
    routing.py
    localization.py
    schedule.py
    optimize.py
    disturbance.py
    validation.py
    plots.py
results/
    tables/
    figures/
logs/
    ai_usage_log.md
```

参数、随机种子和单位约定只能从统一配置读取。正文图表、支撑材料和代码运行结果必须来自同一批冻结结果。

## 版本说明

本目录中的主文档吸收了队内第二版路线、根目录《B题解题总稿》和最新 B 题参赛指南中的有效内容。`B题最终实现路线.md` 是后续编码、联调和验收的唯一实现规范，根目录总稿用于论文叙事和结果汇总。英文原题和组委会最新公告优先级最高，若后续出现勘误或答疑，应在主文档的“口径变更记录”中登记后再修改代码。
